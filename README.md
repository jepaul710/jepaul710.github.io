## 📂 Proyectos Destacados en el Portafolio

### 🕹️ 1. Rock N' Jump
Un vertiginoso videojuego independiente de plataformas arcade en 2D que combina mecánicas clásicas.
*   **Tecnologías:** Unity / C#
*   **Contribución central:** Programación desde cero de las físicas de salto, diseño del sistema de aceleración dinámica por puntuación, integración de partículas VFX/SFX y optimización del bucle principal del juego.
*   **Repositorio:** [Código en GitHub](https://github.com/jepaul710/Rock-N-Jump)

### 🚌 2. Urban Routes Automation
Framework de automatización robusto para pruebas de UI y cálculo de tarifas de una app de movilidad.
*   **Tecnologías:** Python / Selenium WebDriver
*   **Contribución central:** Creación de la arquitectura de pruebas desde cero, simulación automatizada de procesos de reserva complejos y aserciones estrictas de consistencia visual.
*   **Repositorio:** [Código en GitHub](https://github.com/jepaul710/qa-project-Urban-Routes-es)

### 🛒 3. Urban Grocers API Testing
Suite de pruebas backend para la validación de endpoints y microservicios de entrega de alimentos.
*   **Tecnologías:** Python / Postman / HTTP REST
*   **Contribución central:** Scripts automatizados para validar códigos de estado, pruebas destructivas de autenticación e integridad de esquemas JSON.
*   **Repositorio:** [Código en GitHub](https://github.com/jepaul710/qa-project-Urban-Grocers-app-es)
